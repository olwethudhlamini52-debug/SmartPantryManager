# Smart Pantry Manager

## 📱 Project Overview

Smart Pantry Manager is an Android application designed to help users manage ingredients available in their pantry and discover recipes based on the ingredients they already have.

The application helps reduce food waste by encouraging users to use leftover ingredients to prepare meals.

## ✨ Features

* Add pantry ingredients
* Record ingredient quantities
* Save pantry information
* View saved pantry ingredients
* Find recipes based on available ingredients
* View detailed recipes
* Display cooking time
* Display serving information
* Display recipe ingredients
* Display cooking instructions
* Simple and user-friendly interface
* Custom application icon

## 🍳 Recipe Matching

The application checks the ingredients stored in the user's pantry and recommends recipes that can be prepared with those ingredients.

Examples include:

* Egg Omelette
* Egg Sandwich
* Tomato & Egg
* Chicken & Rice
* Potato & Egg
* Vegetable Fried Rice
* Grilled Cheese Sandwich
* Chicken & Potato

## 🛠️ Technologies Used

* Java
* Android
* Android SDK
* Gradle
* Android Studio / Visual Studio Code
* SharedPreferences for local data storage
* XML layouts

## 📂 Main Application Screens

1. Home Screen
2. Add Ingredient Screen
3. Pantry Screen
4. Recipes Screen
5. Recipe Details Screen

## 💾 Data Storage

The application uses Android `SharedPreferences` to store pantry ingredients locally on the device.

Pantry information remains available when the user navigates between screens and reopens the pantry.

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project in Android Studio or Visual Studio Code.
3. Make sure an Android SDK is installed.
4. Connect an Android device or start an emulator.
5. Build the project using Gradle.
6. Install and run the application.

## 🧪 Example

A user can add:

**Ingredient:** Egg
**Quantity:** 2

The application stores the ingredient in the pantry.

When the user selects **Find Recipes**, the application can recommend:

**🍳 Egg Omelette**

The user can then select **View Recipe** to see the cooking time, servings, ingredients and instructions.

## 🎯 Project Objective

The main objective of Smart Pantry Manager is to provide a simple mobile solution for managing pantry ingredients and helping users discover meals they can prepare from the food they already have.
